# SEMESTRE 3-UNIDAD 1
Práctico Experimental 03

Este proyecto implementa una biblioteca con uso de conjuntos y diccionarios en Python.
Se gestionan libros por ISBN, se registran préstamos y devoluciones, y se genera un reporte con estadísticas básicas.

## Archivos
- `biblioteca.py`: programa principal con la lógica y menú interactivo.

## Ejecución
```bash
python biblioteca.py
```
